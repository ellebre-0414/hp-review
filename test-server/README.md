# TWIY 3サイト・テストサーバー用

このフォルダだけを、GitHubの専用リポジトリへ登録するための軽量コピーです。推奨は非公開リポジトリです。GitHub Pages用ではありません。アップロード・公開はまだ行っていません。

## 制作とテストの分け方

- 日々の編集は、今までの塾・アパレル `site/01_current/` と法律事務所の制作フォルダで続けます。このコピーは直接編集しません。
- テスト前に制作側の `tools/test-package/build.mjs` を実行し、同じ `deploy/test-server/` を更新します。日付違いのフォルダ・ZIPは作りません。
- このフォルダ全体がGitHub登録の単位です。制作フォルダ全体を登録しないでください。
- この中の2つのフォルダ名と階層は変更しないでください。既存の相互リンク・サーバーの配信先を維持しています。
- ホームページのHTML・CSS・JavaScript・掲載画像は原本と同一です。未使用画像・旧スクリプト、制作資料、3Dモデル、履歴、確認画像、Mac管理ファイルは含めていません。

## 必要なサーバー

Node.js 22.13以降（今回の確認環境は24系）、常時動くNode.jsプロセス、書き込み可能な永続ディスクが必要です。サーバーの設置先は未定です。GitHubはコードの保管先として使います。

静的ファイル配信ではなく、必ず `npm start` でこのアプリを起動してください。サイト全体を1つの専用ホストのルートに置きます。`/test/` などのサブパスに置く構成は未対応です。

## ローカルでの起動

このREADMEとpackage.jsonがあるフォルダで実行します。

```sh
npm ci --omit=dev --ignore-scripts
npm start
```

依存ライブラリは法律事務所と同じNodemailer 10.0.10に固定しています。`node_modules` はGitHub登録用コピーには含めず、最初に上のコマンドで取得します。サイトにビルド処理はありません。

- 法律事務所: http://127.0.0.1:8787/
- 塾: http://127.0.0.1:8787/TWIY%20BRAND%20HP/site/01_current/index.html
- アパレル: http://127.0.0.1:8787/TWIY%20BRAND%20HP/site/01_current/brand.html

初回だけ、ターミナルに表示される管理者設定リンクを開き、14文字以上の新しいパスワードを設定します。このリンクを他人に共有しないでください。

## テストサーバーでの環境変数

サーバー管理画面の環境変数として指定します。秘密情報をGitHubに書かないでください。

| 変数 | 用途 |
| --- | --- |
| `HOST` | サーバーの指定に従って設定。外部接続を受ける構成では通常 `0.0.0.0`。未指定ならローカル専用 `127.0.0.1`。 |
| `PORT` | サーバー指定のポート。未指定なら `8787`。 |
| `PUBLIC_ORIGIN` | 実際の `https://テスト用ホスト名`。末尾の `/` や追加パスは含めない。 |
| `DATA_DIR` | サーバーの永続ディスク上の専用ディレクトリの絶対パス。未指定ならこのコピー内の `.runtime`。再デプロイで消える一時ディスクを使わない。 |

HTTPSのリバースプロキシからアプリへ転送し、Cookie・Originを維持します。設置先が決まった段階で具体的な設定を確認してください。テストサイトはホスティング側の認証・アクセス制限を付け、一般公開しない構成を推奨します。

## 保存データと機能について（重要）

機能のプログラムは残していますが、現在の保存データを自動で移すコピーではありません。

- **塾・アパレルの管理機能**：従来どおり同じブラウザー内だけの試作版です。サーバーに置くだけでは、編集内容が他の人や他の端末に共有される仕組みにはなりません。新しいURLは別の保存領域です。必要な編集内容は、元のブラウザーでJSONを書き出し、新しいURLの管理画面で内容を確認して手動で読み込み・保存します。元のブラウザー保存データには触れません。
- **法律事務所の管理機能**：Node.js側の認証・SQLite保存・ブログ・経歴・問い合わせ管理を含みます。今回は新しいテスト環境として初期状態から開始します。元の `.data` にある掲載内容・ブログ・管理者情報・受信履歴・メール設定はコピーしていません。元の保存済み内容も再現したい場合は、非公開データの扱いを確認して別途安全に移行します。HTMLを直接開くローカル試作版のブラウザー保存内容も自動移行しません。
- **問い合わせ**：初期状態は受付停止・SMTP未設定です。テストには架空の情報を使ってください。受付を有効にするとSQLiteへ保存します。SMTPを設定すると実メールが送信されるため、設定・送信は別途明示的に確認して行います。
- **アパレル購入**：現状どおり入力・内容確認までです。実際の注文送信・決済機能は元から含まれていません。
- **管理パスワード**：法律事務所のサーバー認証とは違い、塾・アパレルの簡易パスワードは本番用のアクセス制限にはなりません。個人情報・機密情報を登録しないでください。

## 再デプロイで失わないために

`DATA_DIR`、または `.runtime` 内にあるSQLite本体・WAL・SHM・mail-keyは一式で扱います。不要ファイルとして削除しないでください。バックアップする場合は停止後に一式を非公開の保管先へ保存します。GitHubには登録しません。

`.gitignore` は依存ライブラリ・稼働データ・環境変数ファイルを除外します。ただしGitHubのブラウザー画面で手動アップロードする場合は除外が効く前提にせず、これらを選択しないでください。アップロード前に内容を確認します。

現在はサーバーでの実配備・外部メール配信・実注文の検証はしていません。コピー側の機能検証は独立したテストデータを使い、実データと外部メールには触れません。
